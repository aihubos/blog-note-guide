# 블로그 노트

블로그 올인원 v4.53의 주요 로직을 분석하고, 네이버 블로그를 직접 운영할 때 참고할 조건을 정리한 반응형 안내 웹입니다.

## 들어 있는 내용

- 수동 운영 가이드 10개: 이웃 관리, 댓글·답글, 글 발행, 계정·제한
- 프로그램 분석 조건 12개와 각 조건의 근거·한계
- n8n 스타일 노드 흐름도: 전체·이웃 추가·답글/답방·이웃 소통, 분기 탐색과 확대/축소
- [노드 흐름도 바로 열기](https://aihubos.github.io/blog-note-guide/#workflow)
- 네이버 공식 도움말 6개
- 발행 전 체크리스트 8개, 메모 자동 저장, Markdown 다운로드
- 데스크톱 사이드 메뉴와 모바일 하단 메뉴

원본 실행 파일은 실행하거나 수정하지 않았습니다. 인증 변경, 네이버 로그인, 자동 댓글·게시 기능은 포함하지 않습니다. 네이버·토스의 공식 서비스가 아닙니다.

## 분석 범위

분석 기준일: 2026-11-04. REA/Ghidra로 파일 구조를 확인하고 Python 3.14 바이트코드의 상수·명령·호출 관계를 읽었습니다. 주요 발견과 공식 자료는 [분석 보고서](analysis/분석보고서.md)에 있습니다.

정적 분석만 수행했으므로 실제 화면 동작, 외부 서버 설정, AI 분류 정확도는 미검증입니다. 프로그램의 수량·대기·길이 설정을 네이버의 공식 정책 또는 안전한 사용량으로 해석하면 안 됩니다.

## 실행

Node.js 24 기준입니다.

```sh
npm ci
npm run dev
```

미리보기: http://127.0.0.1:5178/

```sh
npm run build
npm run preview
```

`dist/`가 정적 배포 파일입니다. 원본 실행 파일과 추출 자료는 `analysis/private/`에만 보관하고 Git 및 웹 배포에서 제외합니다.

## 배포

`main`에 변경사항을 푸시하면 GitHub Actions가 `dist/`만 GitHub Pages에 배포합니다. 하위 경로에 대응하도록 자산 경로는 상대 경로로 빌드됩니다.

## 저장 방식

체크리스트와 메모는 현재 브라우저의 로컬 저장소에만 보관합니다. 다른 기기·브라우저에는 자동 동기화되지 않으며 사이트 데이터 삭제 시 사라집니다. 로그인이나 서버 저장 없이 사용할 수 있습니다. 필요한 내용은 ‘노트 저장’으로 내려받으세요.
